## 2. Reflection - 3 Questions to Write in Portfolio

**What was hardest?**
Most students say L05 translation and L06 MECE. That is normal. It is thinking, not coding. Coding is easy, thinking is hard. If you struggled there, you learned the real skill that separates analyst from dashboard maker.

Example reflection: I thought data science was Python. Now I know 70 percent is translating business pain to question and breaking MECE before touching Excel.

**What was your L15 project impact?**
Can you say in 30 seconds: I helped pharmacy in Yaba reduce expiry waste from N200k to N80k monthly by switching Supplier A to weekly orders and alert for <45 days expiry, measured by purchases sheet, saving N1.44M yearly? If you can, you can interview. That pitch beats 92 percent accuracy.

Write impact in Naira and time, not model metrics. Recruiters remember Naira saved.

**What would you do differently?**
Write 3 lessons learned in README. Example:
- I would get data dictionary first before cleaning to avoid fixing wrong date column.
- I would define KPI baseline before chart to avoid vanity dashboard.
- I would mask supplier names earlier and check NDPA purpose limitation.

Write reflection in portfolio: What you did, why you chose that problem, what you learned, what failed, what you would improve next.

## 3. Next 90 Days - How to Avoid Tutorial Hell

Tutorial hell = watching 50 intro courses without shipping. You have shipped L15, do not fall back.

**Next 30 days - Ship 2 more real SME problems:**
- One retail: supermarket Surulere, POS business Yaba, barber shop, thrift collector (ajo), restaurant sales.
- One logistics or betting or transport: rider delivery time Apapa, betting churn, danfo transport cost.
Same flow every time: L05 scope 1 page, L06 MECE + 3 hypotheses, L10 KPI from X to Y within Z, L09 ethics check, L14 docs README + dictionary + 1-pager Pyramid, L15 ship in 1 week.
You now have 3 portfolio stories, not 1 Titanic. Each story should have: Problem, data source, method, finding, recommendation, impact in Naira, limitation.

**Days 31 to 60 - Deepen SQL and Excel (WS_02 prep):**
- Master WINDOW functions: ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD, SUM OVER PARTITION, GROUP BY ROLLUP.
- Excel Power Query, Power Pivot, DAX measures: CALCULATE, FILTER, SUMX.
- Build 1 dashboard that refreshes daily automatically without manual copy-paste. Use Power BI dataset scheduled refresh or dbt for transformation.
- Practice: Take your L15 Excel and make it refresh with new data added, no manual steps.

**Days 61 to 90 - Learn Python for Analysis (WS_04 prep):**
- Python for analysis (not ML yet): pandas for cleaning, matplotlib and seaborn for charts, SQLAlchemy to read from DB.
- Redo your L15 project in Python notebook and compare to Excel version: Which was faster? Which would you ship to MD who uses WhatsApp? Learn when Excel is right tool (L08).
- Learn GitHub: Push your 3 projects with README, data dictionary, 1-pager PDF, clean Excel or CSV, and Loom video link. Structure: /data, /docs, /images, README.md.
- Learn how to write commit messages and how to document limitations.

After that: Then learn experimentation and basic ML in WS_02 and WS_05. Not before. ML without L05-L14 is useless and will not ship.

## 4. What Comes After Introduction to Data Science and Analytical Thinking - Course Track

- **Data Analysis with SQL and Excel** - Deep dive into getting and cleaning, JOINs, WINDOW, Power Query, data quality checks.
- **Visualization and Storytelling** - Make MD say yes, Pyramid Principle, dashboard design, one chart one message.
- **Python for Data Analysis** - pandas, numpy, cleaning, EDA, ETL.
- **Statistics and Experimentation** - A/B testing, hypothesis testing, confidence intervals, not just p-values.
- **Machine Learning Basics** - Only after you can do L05-L14 comfortably without notes and have 3 portfolio projects.

You are not ready for ML until you can translate business pain to KPI, break MECE, check ethics, and ship docs MD opens on phone without you.

## 5. Final Checklist - Can You Do These Without Notes?

- Define data science in 1 sentence that business owner in Yaba understands? Example: Using data to make better decisions that save Naira or time.
- Translate vague complaint "Sales down" to 3 analytical questions with source, time window, comparison? Example: What was sales last 30 days vs previous 30 days by branch from pos_sales table?
- Break problem MECE and write 3 testable hypotheses with If true, we will see Z in data?
- Name 5 roles (Analyst, Scientist, Engineer, Analytics Engineer, ML Engineer) and choose tool based on problem not hype, explain why Excel can be right tool?
- Check ethics: privacy, consent, bias, harm, NDPA 2023, and mask personal data, state limitations?
- Define KPI tree, leading vs lagging, avoid vanity metric, write success statement from X to Y within Z as measured by source?
- Explain win pattern (rule first, ship fast, measure Naira, then ML) vs fail pattern (start with ML, no business question, never ships) from L11?
- Move from Data to Information to Knowledge to Wisdom with Nigerian example and show evidence at each layer?
- Pick real SME problem, scope in 1 page using L13 template, get data in 1 day, ship in 1 week with README and 1-pager Pyramid Principle?
- Present with Pyramid Principle: Recommendation first, evidence after, limitations stated, speak Naira not accuracy?

If yes to all 10, you finished ***Introduction to Data Science and Analytical Thinking*** as problem-first analyst. If not, redo L05-L10 and L13-L15, not L01-L04. Thinking is the bottleneck.
